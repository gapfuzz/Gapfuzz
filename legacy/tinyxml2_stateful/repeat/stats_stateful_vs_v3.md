# 반복 측정 결과 — stateful vs stateful_v3

조건: 각 5회/5회, 회당 120초, 같은 회차는 같은 퍼저 시드(1000+회차), xml.dict 사용, ASan+UBSan.
값은 **중앙값 [최솟값–최댓값]**. 커버리지는 라이브러리 소스(tinyxml2.cpp/.h)만 집계.

## 커버리지

| 지표 | stateful | stateful_v3 | A12 | p (Mann-Whitney U, 양측) |
|---|---|---|---:|---:|
| 라인 | 76.81% [75.85–76.96] | 76.88% [76.63–77.18] | 0.72 | 0.3095 |
| 함수 | 71.61% [71.61–71.61] | 71.88% [71.88–71.88] | 1.00 | 0.0079 |
| 영역 | 82.37% [81.52–82.48] | 82.48% [82.37–82.70] | 0.78 | 0.2222 |
| 분기 | 77.99% [76.63–78.53] | 79.89% [79.89–79.89] | 1.00 | 0.0079 |

A12는 무작위로 하나씩 뽑았을 때 오른쪽 하네스가 더 높을 확률(0.5면 차이 없음, 1.0이면 항상 높음).
표본이 5개씩일 때 양측 정확검정으로 나올 수 있는 가장 작은 p는 0.0079입니다.

## 분류 안정성

같은 하네스를 반복했을 때 API 분류가 얼마나 일관된지 봅니다.

| | stateful | stateful_v3 |
|---|---:|---:|
| 모든 회차에서 분류가 같은 API | 303/303 | 300/303 |
| 한 번이라도 도달한 API | 200 | 201 |
| 매 회차 도달한 API | 200 | 201 |

stateful_v3에서 회차마다 분류가 바뀐 API:
- `XMLDocument::Identify(char *, XMLNode **, bool)`: 완전 도달 / 일부 분기 미실행
- `XMLUtil::IsNameStartChar(unsigned char)`: 완전 도달 / 일부 분기 미실행
- `XMLUtil::ToUnsigned(const char *, unsigned int *)`: 완전 도달 / 일부 분기 미실행

stateful_v3에서 매번 도달했지만 stateful에서는 한 번도 도달하지 못한 API: **1개**
