# Claude가 만든 팀 실험용 하네스 (official_llm)

라이브러리마다 gapfuzz의 '하네스에서 고칠 곳'(대조군 제외)을 Claude API에 한꺼번에 맡겨 OSS-Fuzz 하네스를 고치게 하고,
gapfuzz가 컴파일 → 퍼징 → 겨냥 분기 확인 → 크래시 귀속으로 검사해 통과한 하네스입니다. 팀 실험은 이 하네스를 OSS-Fuzz 하네스와 비교합니다.
