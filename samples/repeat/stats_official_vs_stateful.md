# 반복 측정 결과 — official vs stateful

조건: 각 5회/5회, 회당 120초, 같은 회차는 같은 퍼저 시드(1000+회차), xml.dict 사용, ASan+UBSan.
값은 **중앙값 [최솟값–최댓값]**. 커버리지는 라이브러리 소스(tinyxml2.cpp/.h)만 집계.

## 커버리지

| 지표 | official | stateful | A12 | p (Mann-Whitney U, 양측) |

| 라인 | 37.96% [37.74–38.07] | 76.81% [75.85–76.96] | 1.00 | 0.0079 |
| 함수 | 26.04% [26.04–26.04] | 71.61% [71.61–71.61] | 1.00 | 0.0079 |
| 영역 | 45.26% [45.03–45.38] | 82.37% [81.52–82.48] | 1.00 | 0.0079 |
| 분기 | 41.85% [41.44–41.99] | 77.99% [76.63–78.53] | 1.00 | 0.0079 |

A12는 무작위로 하나씩 뽑았을 때 오른쪽 하네스가 더 높을 확률(0.5면 차이 없음, 1.0이면 항상 높음).
표본이 5개씩일 때 양측 정확검정으로 나올 수 있는 가장 작은 p는 0.0079입니다.

## 분류 안정성

같은 하네스를 반복했을 때 API 분류가 얼마나 일관된지 봅니다.

| | official | stateful |
|---|---:|---:|
| 모든 회차에서 분류가 같은 API | 302/303 | 303/303 |
| 한 번이라도 도달한 API | 42 | 200 |
| 매 회차 도달한 API | 42 | 200 |

official에서 회차마다 분류가 바뀐 API:
- `XMLUtil::ReadBOM(const char *, bool *)`: 완전 도달 / 일부 분기 미실행

stateful에서 매번 도달했지만 official에서는 한 번도 도달하지 못한 API: **158개**
